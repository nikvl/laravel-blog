# WORKFLOW

This project follows the standard /workflow skill (Steps 1–11).
Run `/workflow` in Claude Code to start a guided task.

Key rules:
- Backend implementation and tests precede frontend work.
- Run the available tests and checks before proposing a commit; report unavailable checks explicitly.
- Update docs/status.md after every significant change.
- Do not commit or push autonomously.

See ~/.claude/commands/workflow.md for the full workflow.
