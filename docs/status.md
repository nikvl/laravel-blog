# Project Status

> Updated after every significant change.

## 2026-11-16 — Project initialized

- `docs/` initialized via `/workflow`.
- Stack: Laravel package with Inertia/React and Tiptap 2.

## 2026-11-16 — Article media

- Added cursor-position image insertion from a file or URL, with alt descriptions and authenticated, validated uploads to `blog-images` on the configured disk.
- Added editable HTML/CSS/SVG previews using `html-preview` Markdown fences. Reused the existing Tiptap code-block node with a visual node view and lossless serialization rather than adding another content format or database schema.
- Preview documents have sandbox isolation, restrictive CSP and navigation removal. Raw HTML and unsafe Markdown links remain disabled. External resources and scripts inside previews are intentionally unsupported; frames use a fixed 480px height with scrolling.
- Package tests: 10 PHP tests / 41 assertions passed with PHP 8.5 in a Composer Docker container; 19 editor tests passed with Vitest/jsdom.
- Strict TypeScript checks passed for the changed pages/components with a temporary host layout stub. A temporary Vite production build passed (one bundle-size warning).
- Chromium checks passed on a temporary host stand using the actual editor/public pages: file/URL insertion, validation and upload retry/CSRF/busy state, preview/edit/delete/undo/cancel, Markdown import/save/reopen, normal code blocks and bold formatting, mobile public rendering generated by the PHP renderer, blocked external preview requests and no runtime exceptions.
- The browser stand mocked Inertia persistence and upload responses; upload behavior was tested separately through the real Testbench HTTP routes. A consuming Laravel application's build/deployment was not modified or tested. No package lint/PHPStan configuration exists.

## 2026-11-17 — Content-sized transparent previews

- Removed injected white backgrounds, borders, padding and fixed iframe heights from public HTML/SVG previews, the editor and the media dialog. The editor retains its editing toolbar.
- Added shared iframe sizing with load/content/container resize observation and cleanup. Preview dimensions fit the content and stay within the available width; SVGs without explicit dimensions use their viewBox size.
- Public rendering normalizes previously saved preview documents, so existing posts do not need to be saved again. User-provided content backgrounds and spacing remain part of the content.
- Frames permit only `allow-same-origin` for parent-side measurement; scripts remain blocked by sandbox and CSP. External resources and navigation remain disabled.
- Verification: 22 Vitest tests, 12 PHP tests / 52 assertions, strict TypeScript checks and a temporary Vite production build passed (bundle-size warning only). Chromium checks covered editor/dialog/public rendering, existing saved iframes, transparency, small/long/empty/positioned content, viewBox-only SVG, mobile resizing and blocked script execution without runtime errors.
- Browser checks used temporary layout/Inertia stubs; a consuming application's deployment was not changed. No lint script is configured in this package.
